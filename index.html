🗂️ Metodología ARGOS — 10 pasos
  1. Define objetivo. Nombre completo, cédula, apodos, ciudad conocida.
  2. Activa ARGOS. El motor consulta todas las fuentes automáticamente.
  3. Revisa registros oficiales. Registraduría → SIMIT → Rama Judicial → Procuraduría → Fiscalía.
  4. Verifica sector financiero. Superfinanciera, Supersociedades, CIFIN, Datacrédito.
  5. Cajas de compensación. Compensar, Colsubsidio, Cafam, Comfama — afiliación laboral.
  6. Contratos SECOP. La API retorna contratos reales en tiempo real.
  7. Cruce de redes sociales. LinkedIn, Facebook, Instagram, TikTok simultáneamente.
  8. Cruce de imagen. Yandex + PimEyes + Google Lens para identificar visualmente.
  9. Cruza y valida. ARGOS calcula porcentaje de certeza según fuentes confirmadas.
  10. Documenta. Imprime el informe con fecha, fuentes y porcentaje de certeza.
