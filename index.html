🗂️ Metodología ARGOS v2.0 — 12 pasos
  1. Define objetivo. Nombre completo, cédula, apodos, ciudad, empresa conocida.
  2. Activa ARGOS. El motor consulta 30+ fuentes automáticamente.
  3. Registros de identidad. Registraduría → SIMIT → VUR → Supernotariado.
  4. Antecedentes legales. Rama Judicial → Procuraduría → Contraloría → Fiscalía → Policía.
  5. Educación y certificaciones. SENA → ICFES → SNIES → RETHUS → universidades.
  6. Sector salud. RETHUS, INVIMA — si es profesional de salud o del sector farmacéutico.
  7. Contratos públicos. SECOP II API + ANI + SECOP I — si ha contratado con el Estado.
  8. Sector financiero. Superfinanciera, Supersociedades, CIFIN, Datacrédito, Sistecrédito.
  9. Cajas de compensación. Confirman afiliación laboral activa o histórica.
  10. Redes sociales. LinkedIn, Facebook, Instagram, TikTok, Twitter/X simultáneamente.
  11. Cruce de imagen. Yandex + PimEyes + Google Lens para identificación visual.
  12. Cruza y documenta. ARGOS calcula certeza. Imprime informe con evidencia.
