🗂️ Metodología ARGOS v3.0
  1. Define objetivo. Nombre completo o cédula. Con cédula = datos más exactos.
  2. Activa ARGOS. El motor consulta APIs reales: SECOP II, PEP, SIRI, Contraloría.
  3. Lee los resultados directos. ARGOS muestra los datos en pantalla — contratos, cargos, sanciones.
  4. Verifica manualmente en Rama Judicial, SIMIT, Registraduría, SENA, SNIES, RETHUS.
  5. Redes sociales. LinkedIn, Facebook, Instagram, Twitter/X — búsquedas pre-armadas.
  6. Imagen. Tab 📷 → Yandex + PimEyes para identificación facial cruzada.
  7. Documenta. Usa 🖨️ Imprimir o 📋 Copiar para el informe final.
💡 Por qué ARGOS v3 es diferente
v1-v2: Solo abría links estáticos. No consultaba nada.
v3: Consulta APIs REST reales de datos.gov.co con CORS abierto. Los resultados aparecen directamente en pantalla: contratos reales, sanciones reales, cargos públicos reales.
Limitación honesta: SIMIT, Registraduría, Datacrédito, Rama Judicial no tienen APIs públicas con CORS — requieren verificación manual.
