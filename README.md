# 🔍 InvestigaYa — OSINT Colombia

Herramienta de investigación OSINT con JavaScript completo.

## 🌐 App en vivo (GitHub Pages)

👉 **https://jeissonalberto.github.io/investiga-ya-osint-app/**

## Funcionalidades

- 👤 **Nombre** — campos de texto funcionales, busca en 14 fuentes al instante
- 🪪 **Cédula** — 14 bases de datos oficiales colombianas
- 📷 **Foto** — búsqueda inversa en 7 motores
- 📧 **Email / Teléfono** — 8 fuentes especializadas
- 🕵️ **Dorks** — generador dinámico con copiar y buscar
- 📚 **Directorio** — todas las fuentes con estado y tipo
- 🗂️ **Metodología** — 10 pasos del investigador profesional

## Tecnología

HTML5 + CSS3 + JavaScript vanilla. Sin dependencias. Sin frameworks.
